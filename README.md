# Чат-бот для заявок на сайты (Telegram)

Бот проводит клиента по сценарию (новый сайт, доработка, продвижение, примеры работ, контакты), собирает ответы и отправляет готовую заявку менеджеру в Telegram.

Весь сценарий лежит в таблице `scenario.xlsx`: тексты, кнопки, порядок вопросов, настройки. Заказчик правит таблицу сам (лучше в Google Таблицах), программист не нужен. Подробная инструкция есть на первом листе таблицы.

## Запуск

```bash
py -3.13 -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
copy .env.example .env    # вписать BOT_TOKEN
.venv/Scripts/python main.py
```

Дальше:
1. Написать боту `/id` и вставить свой ID в лист "Настройки" → "Чат для заявок (ID)" и "Администраторы". Можно указать ID группы, тогда заявки будут приходить всей команде.
2. Отправить боту `/reload`.

Если Telegram доступен только через прокси, укажите его в `.env`: `PROXY=http://127.0.0.1:10808`. Без этой строки бот берёт прокси из переменной `HTTPS_PROXY`, а если её нет, подключается напрямую.

## Сценарий в Google Таблицах

1. Загрузить `scenario.xlsx` в Google Диск и открыть как Google Таблицу ("Файл → Сохранить как Google Таблицу").
2. Доступ: "Все, у кого есть ссылка" → "Читатель" (редактирует только владелец).
3. В `.env` указать `SCENARIO=https://docs.google.com/spreadsheets/d/.../edit`.

Бот перечитывает таблицу раз в 5 минут (настраивается) или сразу по команде `/reload`. Если в таблице ошибка, бот остаётся на прошлой версии и пишет администратору, в какой строке ошибка.

## Команды

| Команда | Кто | Что делает |
|---|---|---|
| `/start` | все | начать диалог заново |
| `/menu` | все | главное меню |
| `/id` | все | показать ID чата (для настроек) |
| `/reload` | админы | перечитать таблицу сценария |
| `/leads` | админы | выгрузить все заявки в Excel |

Менеджер может ответить (reply) на заявку или вопрос в чате заявок, и бот перешлёт ответ клиенту.

## Устройство

- `bot/scenario.py`: чтение и проверка таблицы.
- `bot/engine.py`: логика диалога, не зависит от Telegram.
- `bot/telegram_bot.py`: Telegram (aiogram 3), заявки, напоминания, автообновление сценария.
- `bot/storage.py`: SQLite (`data/bot.db`): диалоги, заявки, переписка.
- `tools/build_scenario.py`: собирает исходный `scenario.xlsx` по ТЗ.
- `tests/`: прогон всех веток сценария и случайные прогоны (`.venv/Scripts/python -m pytest`).
